一、新增：智谱 GLM-4.7-Flash（免费）

设置页的翻译服务里多了一个明确标着"免费"的选项。它和「Google 翻译（免费）」的区别是：

                      Google 翻译（免费）      智谱 GLM-4.7-Flash（免费）
  需要 API Key              不需要                   需要（免费注册）
  国内能否直连              不能，要代理              能，不需要任何代理
  翻译类型                  通用机器翻译              AI 翻译
  支持「AI 翻译专家」        不支持                   支持
  外贸术语与语气控制         做不到                   可以

简单说：如果你在国内、又不想折腾代理，这是目前最省事的选择。

二、怎么用（三步）

1. 打开 open.bigmodel.cn 注册（手机号即可），在控制台的「API Keys」页创建一个 Key
2. 扩展 → 设置 → 翻译服务 → 选「智谱 GLM-4.7-Flash（免费）」
3. 把 Key 粘贴到 API Key 框，点"测试连接"

API 地址和模型名已经内置好了，不用填。它也不需要域名和服务器。

三、为什么值得用它

· 不用代理：接口域名在国内可以直接访问，不受你的网络环境影响。
· 免费：glm-4.7-flash 目前是智谱的免费模型，个人使用不需要充值。
· 质量更高：AI 翻译在长句、语气和上下文上明显强于通用机器翻译。
· 能控术语：支持「AI 翻译专家」指令，可以把外贸术语、固定报价口径写进去。

四、关于 DeepL

DeepL 是专业翻译引擎，响应速度通常比大模型快，术语一致性也更稳定。
但用它有两个前提，请先确认能接受：

· 国内需要代理：DeepL 的 API 域名在国内访问不到，必须挂代理。
· 免费版每月只有 50 万字符额度：聊天窗口批量翻译会一次性翻译很多条消息，消耗比较快，
  用完后当月就不能再用了。

另外，DeepL 在中文与英文之间的表现不如它在欧洲语言之间那么突出。

所以：如果你已经在用代理、且翻译量不大，DeepL 是个好选择；如果你想要国内直连且不想管额度，
智谱免费档更合适。

五、其他

· 「智谱 GLM」改名为「智谱 GLM（自选模型）」，模型名可以自己改，方便以后换成更强的付费模型。
· 回归测试从 24 项增加到 25 项，新增一条盯住免费档：下拉里必须能看到"免费"字样、
  只填 API Key 就能工作、模型名正确。
