TransMate 3.9.0 更新

1. 新增「Google 翻译（免费）」：不用填 API Key，装上就能翻译，默认就用它。
2. 修复：WhatsApp 聊天翻译遇到超长消息时，可能同一批十几条消息一起失败——现在只影响真正失败的那条。
3. 修复：在单行输入框里翻译多行内容时，明明已经写进去了，却提示"页面阻止了自动写入"。
4. 修复：长消息重试时容易只翻一半就被截断。
5. 优化翻译速度：记住可用的 Google 域名、失败时并行切换、同一句话重复翻译走缓存。

更新后浏览器会提示重新授权一次（因为新增了 Google 翻译域名的访问权限），在扩展管理页点"允许/重新启用"即可。

已配置的翻译服务、API Key、模型、翻译专家、外观和快捷键全部保留，老用户的服务选择不会被改动。

一、新增：Google 翻译（免费档）

· 不需要 API Key，安装后开箱即用，默认就是它。
· 自动在 3 个 Google 翻译域名之间轮换，代理规则只放行部分域名时也能用。
· 长文本自动分段翻译再拼接，不会因为太长而失败。
· 失败时说明具体原因（网络连不上 / 被限流 / 需要验证），不再只提示一句"翻译失败"。

免费档的限制，请先看清楚再用：

· 国内需要代理才能访问 Google，没有代理用不了。
· 按出口 IP 限流。短时间大量翻译可能被临时限制，稍等几分钟或换个节点即可。
· 它调用的是 Google 网页翻译接口，属于纯机器翻译，不接收「AI 翻译专家」指令。需要外贸术语、仓储设备术语和语气控制时，请在设置里改用 Gemini、DeepSeek 等 AI 服务（需自备 API Key）。
· 这是 Google 的非公开接口，不受官方支持，可能随时变动或失效。重要客户沟通建议仍使用已配置的 AI 服务。

二、修复

1. WhatsApp 聊天翻译整批失败
   以前遇到一条超长消息，可能导致同一批最多十几条消息一起翻译失败，并且十几秒内不再重试。
   现在会自动降级为逐条重试，只有真正失败的那一条受影响，其余消息正常显示译文。

2. 输入框翻译误报"页面阻止写入"
   在单行输入框里翻译多行内容时，浏览器会去掉换行符，程序因此误判为写入失败，提示"页面阻止了自动写入，请按 Ctrl+V 粘贴"——其实内容已经写进去了。
   现在会按输入框能容纳的格式正确写入并直接完成，不再误报。

3. 长消息重试时输出长度不足
   逐条重试时原本使用固定的输出长度，长消息容易被截断成半句。现在按文本长度动态估算。

4. 设置页新增提示
   选择 DeepL 或 Google 翻译（免费）时，会明确提示这两个服务不接收「AI 翻译专家」指令。

三、翻译速度优化

1. 记住上次可用的 Google 域名
   以前每次翻译都可能重新探测域名。现在会记住上次成功的那个，正常情况下只发一个请求。

2. 失败时并行切换域名，超时收紧
   以前是三个域名依次重试，每个最多等 20 秒，最坏情况要等将近一分钟才出结果。现在第一个失败后同时探测其余域名，单次请求超时也从 20 秒收紧到 6 秒，最坏等待降到十几秒以内。

3. 重复翻译同一句话直接返回缓存
   同一句话、同一目标语言、同一翻译专家再次翻译时不再发请求，立刻出结果。缓存只对 Google 免费档和 DeepL 这类"同样输入必定同样输出"的服务生效；AI 服务不缓存，方便你重新生成一版。

4. 聊天批量翻译并发数从 3 提到 4
   一屏聊天记录的翻译等待时间大约缩短四分之一。

四、更新后需要做的一件事

本次新增了对 Google 翻译域名的访问权限，浏览器会提示重新授权（扩展可能被暂时停用）。

处理方式：打开 chrome://extensions/ （Edge 为 edge://extensions/），找到 TransMate，点击"重新启用"或"允许"，完成即可。

五、不受影响的部分

· 已配置的翻译服务、API Key、模型、AI 翻译专家、外观设置、快捷键全部保留。
· 老用户当前选择的服务不会被改成免费档。免费档只作为新安装的默认值。
· 时区与客户语言功能没有任何改动。

六、如何切换到免费档

设置页 → 翻译服务 → 选择「Google 翻译（免费）」，不需要填写任何内容，点"测试连接"可以立刻验证当前网络是否可用。

七、其他

· 整理了内部的服务适配代码，把"哪些服务不需要模型名称"集中到一处声明，避免以后新增服务时漏改。
· 版本号：3.8.2 → 3.9.0
