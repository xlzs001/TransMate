TransMate v3.9.13

作者：Mark

本扩展包含：
1. TransMate 多语言商务翻译
2. WhatsApp 客户号码归属地区与当地时间
安装：
1. 先解压 ZIP 文件。
2. Chrome 打开 chrome://extensions/，Edge 打开 edge://extensions/。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的扩展文件夹。
5. 建议停用旧版本和旧的时区扩展，以免功能重复触发。
6. 打开扩展设置，选择翻译服务，填写 API Key、API 地址和模型，然后点击“测试连接”。

内置聊天窗口翻译：
- 启用“允许快捷键”后，聊天窗口翻译仍需通过快捷键开启；打开开关本身不会立即翻译。
- 默认快捷键为 Alt+Q，可在设置页点击快捷键输入框后录制任意包含 Ctrl、Alt 或 Meta 的组合键。
- 快捷键输入框使用窗口捕获录制：按住 Alt 后再按字母、数字或符号即可，录制成功后会显示完整组合键。
- 快捷键按物理按键码识别，兼容输入法状态；总开关关闭时快捷键不会触发翻译。
- 第一次按快捷键会翻译并显示，第二次会关闭并移除译文，第三次会重新翻译显示。
- 浏览器已经占用的组合键会在录制时提示更换；旧设置中的 Ctrl+数字会自动迁移为 Alt+Q。
- 翻译会话开启后会读取当前聊天区全部已加载消息，并继续处理新消息，不需要设置翻译条数。
- 翻译会话只对当前这一个联系人生效：切换到别的联系人会自动结束，需要翻译时请再按一次快捷键。
- 最新消息优先处理，每批最多合并 12 条消息发送，减少等待和 API 请求次数。
- 每条消息会在原文末尾、时间戳前显示 11px 小型翻译进度圆环；该条完成后立即消失，失败时短暂显示红色。
- 图片或视频的引用回复会排除引用预览、媒体时长和时间戳，仅翻译引用下方本次发送的正文。
- 左侧联系人列表、搜索结果和消息摘要不会被翻译。
- 支持双语对照、仅译文、仅原文三种显示方式。
- 支持全部消息或仅客户消息、四种译文样式、颜色、背景和字号。
- 默认屏蔽右侧聊天区中第三方翻译插件插入的译文，防止中文译文干扰客户语言识别。
- 翻译结果按“原文 + 目标语言”缓存，相同内容不会重复请求；同时最多发起两个请求。
- 建议在其他翻译插件中把 web.whatsapp.com 加入“不翻译网站”，避免两个扩展同时消耗接口额度。

翻译服务：
- 默认使用「Google 翻译（免费）」：无需 API Key，安装即可翻译。它调用 Google 网页翻译接口，属于非公开接口，按出口 IP 限流；国内需要代理才能访问，节点访问不到 Google 或 IP 被限流时会提示具体原因。
- 免费接口不接收「AI 翻译专家」指令，只做通用机器翻译；需要垂直术语（外贸、仓储设备）和语气控制时，请改用下面的 AI 服务。
- 免费接口单次请求按约 1200 字符分块，长文本会自动分段翻译后拼接。
- 推荐「智谱 GLM-4.7-Flash（免费）」：国内可直连、不需要任何代理，模型本身免费。到智谱开放平台注册后创建一个 API Key 填进去即可，地址和模型名已内置，不用填。翻译质量优于通用机器翻译，并且支持「AI 翻译专家」指令，能控制外贸术语和语气。
- 关于 DeepL：它是专业翻译引擎，响应通常比大模型快，术语也更稳定；但国内需要代理才能访问，免费版每月只有 50 万字符额度，聊天窗口批量翻译会消耗得比较快。
- 可选 Gemini、OpenAI、Claude、DeepSeek、Groq、OpenRouter、Qwen、智谱 GLM（免费档与自选模型）、硅基流动、Azure OpenAI、DeepL、Ollama 和自定义 OpenAI 兼容接口。
- 普通输入框翻译和 WhatsApp 聊天翻译共用当前选中的服务。
- 填写 API Key 后，点击“获取可用模型”即可读取服务支持的模型；候选项会按翻译适用度排序，优先标注推荐模型，并在原模型输入框下方显示大致功能。点击候选项即可选中，用户也可以手动填写模型 ID。DeepL 和 Azure OpenAI 需要手动配置。
- WhatsApp 的“地区与当地时间”弹窗会显示“AI 翻译专家”，可直接选择自然通用、忠实直译、自然意译、三种聊天语气、商务英语、专业外贸、销售沟通或仓储设备；切换后立即保存并用于后续翻译。
- 选择翻译服务后，API Key 标题右侧会显示对应服务的官方申请入口；Ollama 显示本机配置说明，自定义接口不显示入口。
- 自定义接口首次保存或测试时，Chrome 会询问是否允许访问该 API 域名。
- API Key 和设置只保存在当前浏览器的扩展本地存储中。
- API Key 右侧可选择 AI 翻译专家：自然通用、忠实直译、自然意译、自然聊天、亲切聊天、幽默聊天、商务英语、专业外贸、销售沟通和仓储设备。
- 默认“自然通用”会结合上下文保留语气与格式，生成自然、准确且无机器翻译感的译文。
- AI 翻译专家同时应用于普通输入框、WhatsApp 输入框和聊天窗口批量翻译。

时区外观设置：
- 位置：标题栏、四个页面角落或自定义拖动。
- 自定义拖动：先在设置中选择“自定义拖动位置”并保存，然后在 WhatsApp 页面拖动标签。
- 地区与时间采用无边框、无背景的文字显示。
- 默认跟随“在线/最后上线时间”显示，例如：加纳 当地时间：15:05。
- 当地时间固定采用24小时制。
- 可更改文字色、时间强调色和显示大小。
- 可用水平/垂直微调进行精确定位。

注意：
- 客户地区按照电话号码注册国家推断，不等于客户当前所在地。
- 墨西哥号码支持 10 位本地格式、+52 国际格式，以及 WhatsApp 旧版 +521 格式；旧格式会自动归一化。
- 多时区国家会先采用常用时区，可点击 WhatsApp 页面上的时间标签进行调整。
- 从 v2.5.0 升级时会自动迁移原有 Gemini Key 和模型配置。
- 翻译语言可选择自动识别，也可以在弹窗中手动切换。
- 自动识别会综合当前 WhatsApp 对话最近五条不同的客户文字回复，并显示识别置信度。
- 支持更多小语种；过短或模糊的信息不会覆盖该联系人的已有识别结果。
- 自动识别会排除第三方翻译插件插入的中文译文，优先读取客户原文。
- 点击 WhatsApp 顶部地区时间，可在“客户语言”下拉框中为当前联系人手动锁定语言。
- 号码识别不准时，可在同一弹窗里手动填写号码并保存；手动填写的号码优先级最高，不会被自动识别结果覆盖。
- 详情弹窗会根据聊天区域空间自动选择展开方向，并在小窗口中启用滚动，避免内容被裁切。
